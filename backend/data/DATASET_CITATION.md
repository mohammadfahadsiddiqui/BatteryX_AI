# Synthetic Battery Dataset

## Citation and Reporting Guidelines

As per the project requirements, when presenting this dataset in reports or demonstrations, **do not** write "Source: NASA" for this CSV. 

Please use the following official designation:

**Dataset Source:** 
> Synthetic Battery Dataset generated for BatteryX AI prototype, based on battery-aging and degradation relationships reported in publicly available battery research datasets.

## Real-World Validation Sources

For real-world validation references in your presentations, it is recommended to cite these actual sources:

* NASA Li-ion Battery Aging Dataset
* NASA Prognostics Center of Excellence Data Repository
* CALCE Battery Research Data
* CALCE Battery Anomaly Detection Data

## Best Presentation Wording

When presenting BatteryX AI to stakeholders, use this recommended phrasing:

> *"BatteryX was initially developed and tested using a synthetic 10,000-record dataset designed around realistic battery degradation patterns. Future validation will use publicly available NASA and CALCE experimental datasets."*
